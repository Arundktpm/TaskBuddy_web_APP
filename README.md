# TaskBuddy_web_APP

## ⭐ TaskBuddy – A Simple & Smart Task Manager

 TaskBuddy is a clean and intuitive task-management web app designed to help users organize their daily activities with ease. It provides a distraction-free interface where users can create, track, and complete tasks effortlessly. Whether it’s managing daily routines, planning goals, or listing quick reminders, TaskBuddy offers a smooth and efficient workflow for staying productive.

## ✨ Features

✔ Add, edit, and delete tasks

✔ Mark tasks as completed

✔ Clean and modern UI

✔ Lightweight and fast

✔ Uses LocalStorage to save tasks automatically

✔ Fully responsive design for mobile & desktop

## 🎯 Purpose

TaskBuddy focuses on simplicity. No complex menus or features—just a clean interface that helps users stay on top of their tasks without distractions.

## 🛠 Tech Stack

* HTML, CSS, JavaScript
* LocalStorage for data persistence

```` git clone https://github.com/Arundktpm/TaskBuddy_web_APP.git ````
